A dependency-free, drop-in replacement for marked 18.1.3: `parse.js` renders Markdown to exactly the HTML `marked.parse` returns with marked's default options, but faster. The driver `main.ts` reads every case from `/input/cases.json`, renders each with `parse`, and writes the HTML strings in order to `/output/html.json`.

## Run it

```sh
node main.ts
```
